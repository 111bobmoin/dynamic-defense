# 抗体泛化独立演示模块

本目录独立承载“抗体泛化”演示功能，不改变项目原有总览界面和未知威胁检测界面。

## 接入边界

- 后端接口：`GET /api/antibody`
- 页面入口：点击原系统中的“抗体泛化”后进入 `/antibody.html`
- 静态资源：`/antibody_generalization/antibody.css` 与 `/antibody_generalization/antibody.js`

## 演示闭环

1. 启动攻击：`LLDP + 横向移动` 攻击链，形成 `host1 → m1 → m3 → m4 → m7 → server1` 路径。
2. 提取攻击特征：产出流量、日志、行为图三类证据，形成 `hybrid_feature.json`。
3. 泛化并生成新型攻击：只生成同源/邻近的 LLDP 辅助横向移动变体，不跳转到流量洪泛或 Web 利用等无关类别。
4. 防御标签映射：将 LLDP 侦察、凭据探测、东西向横向移动映射到邻居发现限制、登录限速和微隔离策略。
5. 验证与关系推理：`BELONGS_TO_CLUSTER`、`EVOLVED_FROM`、`RELATED_CLUSTER` 三类图关系和抗体有效性指标。

## 可解释指标

- 检测覆盖率：成功检测攻击样本数 / 总攻击样本数
- 误报抑制率：1 - 误报次数 / 正常流量样本总数
- 规则泛化度：变异攻击检测数 / 变异攻击总数
- 抗体有效性：`0.4 × 检测覆盖率 + 0.3 × 误报抑制率 + 0.3 × 规则泛化度`
